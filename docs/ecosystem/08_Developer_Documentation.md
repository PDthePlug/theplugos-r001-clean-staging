# 08. Developer Documentation

## Purpose
Comprehensive documentation to onboard and guide independent engineering teams in building on ThePlugOS.

## Core Guides
- **Architecture Guide:** Explains the Kernel, Platform Services, and Event Engine.
- **SDK Guide:** How to interact with `@plugos/sdk`.
- **DDK Guide:** Using the Domain Development Kit.
- **CLI Guide:** Command reference.
- **Rules & Workflows Guide:** Declarative business logic.
- **Storage & Synchronization:** CQRS, Event Sourcing, and Offline-first principles.
- **Security Guide:** Identity and authorization concepts.
- **Testing & Certification Guide:** Passing the certification framework.

# 12. Engineering Operations Manual

## Purpose
Guidelines for the core platform maintainers on how to support and evolve the ecosystem.

## Topics
- **Release Management:** Triaging and merging changes to `@plugos/core` safely.
- **SDK Evolution:** Expanding the SDK without breaking backwards compatibility.
- **Certification Maintenance:** Updating the Certification Framework rules.
- **Incident Response:** Debugging live domain issues without modifying core logic.

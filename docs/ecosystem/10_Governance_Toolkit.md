# 10. Governance Toolkit

## Purpose
Automated validation of architectural integrity and engineering standards.

## Automation Checks
- **Constitutional Compliance:** Rules engine asserts that code and configuration don't violate core architecture.
- **ADR Compliance:** Verifies architecture aligns with approved decision records.
- **Performance Budgets:** Fails builds if state projection or event processing exceeds latency thresholds.
- **Security Standards:** Audits permissions and exposes unprotected endpoints.

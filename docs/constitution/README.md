# ThePlugOS Constitution 

This directory contains the operational and engineering artefacts derived from ThePlugOS Project Initialization Protocol v1.0. These documents form the permanent source of truth for the project.

- **[01_PRINCIPLES.md](./01_PRINCIPLES.md)**: Constitutional, Engineering, Product, System, and Architectural principles.
- **[02_STANDARDS.md](./02_STANDARDS.md)**: Documentation, Code, API, Database, Testing, and Deployment standards.
- **[03_DECISION_FRAMEWORK.md](./03_DECISION_FRAMEWORK.md)**: The framework used to evaluate every future engineering decision.
- **[04_KNOWLEDGE_BASE.md](./04_KNOWLEDGE_BASE.md)**: Core concepts, dependencies, and assumptions.
- **[05_GAP_ANALYSIS.md](./05_GAP_ANALYSIS.md)**: Identification of missing elements and recommended additions.
- **[06_READINESS_ASSESSMENT.md](./06_READINESS_ASSESSMENT.md)**: Evaluation of the project's readiness for engineering construction.
- **[07_ENGINEERING_CHARTER.md](./07_ENGINEERING_CHARTER.md)**: Role identity, core engineering philosophy, architectural discipline, and decision rules.

> **Engineering Lock:** No code generation begins until all constitutional artefacts are complete and any architectural gaps (identified in the readiness assessment) are resolved. Every future PRD, ADR, API specification, and implementation plan must be validated against these documents.
